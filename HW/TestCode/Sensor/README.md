# Sensor Test Code

센서 단독 테스트 폴더입니다. 각 센서가 ESP32에서 정상 인식되는지, 측정값이 시리얼 모니터로 출력되는지 확인합니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `I2C_Seaner/I2C_Seaner.ino` | I2C 버스에 연결된 장치 주소를 검색합니다. 폴더명은 현재 프로젝트 이름 그대로 유지합니다. |
| `BME280/BME280.ino` | BME280 주변 온도, 습도, 기압 측정 테스트입니다. |
| `BH1750/BH1750.ino` | BH1750 조도 측정 테스트입니다. |
| `MPU6050/MPU6050.ino` | MPU6050 가속도, 자이로 측정 테스트입니다. |
| `MAX30102/MAX30102.ino` | MAX30102 RED, IR 원시값과 심박 관련 측정 테스트입니다. |
| `MAX30205/MAX30205.ino` | MAX30205 피부 온도 측정 테스트입니다. |
| `README.md` | 본 폴더 설명 문서입니다. |

## 공통 배선

| 기능 | ESP32 핀 |
| --- | --- |
| SDA | GPIO21 |
| SCL | GPIO22 |
| VCC | 3.3V |
| GND | GND |

## 센서 주소

| 센서 | 예상 주소 |
| --- | --- |
| BME280 | `0x76`, `0x77` |
| BH1750 | `0x23`, `0x5C` |
| MPU6050 | `0x68`, `0x69` |
| MAX30102 | `0x57` |
| MAX30205 | `0x48`, `0x49` |

## 권장 테스트 순서

```text
1. I2C_Seaner로 연결된 주소 확인
2. 확인된 주소와 센서 예상 주소 비교
3. 각 센서 단독 스케치 업로드
4. 시리얼 모니터에서 값 출력 확인
5. 값이 비정상이면 배선, 전원, 주소를 먼저 점검
```
