
# Smart Shield 보유 부품 현황

## 1. 문서 목적

이 문서는 Smart Shield 캡스톤 프로젝트에서 현재 실제로 보유 중인 하드웨어 부품을 정리한 문서이다.

본 문서는 최종 회로 구성, 전원 설계, 배터리 사용 시간 계산, 시연 준비, 보고서 작성 시 기준 자료로 사용한다.

현재 보유 부품을 기준으로 작성하며, 아직 배송되지 않은 부품은 별도로 구분한다.

---

## 2. 프로젝트 하드웨어 기준

Smart Shield는 ESP32 기반 PPE 웨어러블 안전 보조 시스템이다.

목표는 작업자의 환경 데이터, 생체 신호, 자세 및 움직임 데이터를 수집하고, BLE를 통해 Android 작업자 앱으로 전송하여 위험 가능성을 판단하는 것이다.

기본 하드웨어 구성은 다음과 같다.

```text
ESP32 DevKit
BME280 또는 BME/BMP280 계열 환경 센서
BH1750 조도 센서
MPU6050 자세 센서
MAX30102 심박수 / 산소포화도 센서
MAX30205 계열 피부 접촉 온도 센서
RGB LED
진동모터
부저
전원 모듈
배터리 또는 USB 전원
````

> 본 시스템은 의료기기가 아니다.
> 체온, 심박수, 산소포화도 값은 의료 진단 목적이 아니라 산업안전 보조 판단값으로 사용한다.

## 4. 메인 제어부

### 4-1. ESP32 DevKit V4 / ESP32-WROOM-32E

| 항목       | 내용                                   |
| -------- | ------------------------------------ |
| 확인 상태    | 확인 완료                                |
| 사진 표기    | `ESP32-WROOM-32E`, `ESP32_DEVKIT V4` |
| 역할       | 메인 MCU, BLE 통신, 센서 수집, 출력 장치 제어      |
| 사용 가능 여부 | 사용 가능                                |

### 주요 역할

```text
BLE Peripheral / GATT Server
I2C 센서 데이터 수집
센서 payload 생성
Android 작업자 앱으로 BLE Notify 전송
Android 작업자 앱에서 BLE Write 명령 수신
RGB LED / 진동모터 / 부저 제어
```

### 주의사항

```text
ESP32는 3.3V 로직을 사용한다.
I2C 센서도 가능하면 3.3V 기준으로 연결한다.
5V 입력은 USB 또는 5V 핀을 통해 공급할 수 있으나, 3.3V 핀에 직접 전원 공급하는 방식은 신중히 사용한다.
BLE 동작과 출력 장치 동작 시 순간 전류가 증가할 수 있다.
```

| 항목       | 내용                                                          |
| -------- | ----------------------------------------------------------- |
| 확인 상태    | 확인 완료                                                       |
| 사진 표기    | `ESP32S 38P/V4/Gouuu Expansion board`, `DC6.5-16V`, `USB5V` |
| 역할       | ESP32 핀 확장, 센서 및 모듈 연결 편의 제공                                |

### 확인된 특징

```text

센서 VCC에 5V가 공급되는 구조라면 I2C 센서 손상 가능성이 있다.
시연 전 멀티미터로 각 전원 핀 전압을 확인해야 한다.
```

## 5-4. Keyestudio MAX30102 심박수 / 산소포화도 센서 모듈

| 항목       | 내용                                                          |
| -------- | ----------------------------------------------------------- |
| 확인 상태    | 확인 완료                                                       |
| 사진 표기    | `MAX30102`, `keyestudio`, `SCL`, `SDA`, `VCC`, `GND`, `INT` |
| 역할       | 심박수, 산소포화도 추정                                               |
| 통신       | I2C                                                         |
| 사용 가능 여부 | 사용 가능, 단 검증 필요                                              |

### 프로젝트 데이터 키

```text
HR
SPO2
```

### 핀 구성

주 사용 핀:

```text
SCL
SDA
VCC
GND
```

보조 핀:

```text
INT
IRD
RD
GND
```

### 연결 기준

| 센서 핀 | ESP32 연결 |
| ---- | -------- |
| VCC  | 3.3V 권장  |
| GND  | GND      |
| SCL  | GPIO22   |
| SDA  | GPIO21   |
| INT  | 선택 사용    |

### 중요한 구분

현재 보유한 모듈은 사진 기준으로 `DFRobot SEN0344`가 아니라 `Keyestudio MAX30102` 모듈이다.

따라서 기존 SEN0344 기준처럼 모듈 내부에서 HR / SpO2 계산값을 안정적으로 제공한다고 단정하면 안 된다.

### 주의사항

```text
MAX30102는 움직임, 압박, 외부광에 매우 민감하다.
손목 착용 시 측정 안정성이 낮아질 수 있다.
HR은 절대값보다 변화 추세를 중심으로 사용한다.
SpO2는 열스트레스 핵심 지표가 아니라 응급 보조 플래그로만 사용한다.
SpO2 단독으로 위험도를 올리지 않는다.
```

### 추가 검증 필요

```text
I2C 주소 확인
라이브러리 동작 확인
손목 착용 상태 측정 안정성 확인
외부광 차단 여부 확인
움직임 중 HR / SpO2 튐 여부 확인
```

```text
IN

```

### 연결 기준

| 모듈 핀 | ESP32 연결                |
| ---- | ----------------------- |
| IN   | GPIO 출력 핀               |
| VCC  | 3.3V 또는 5V, 모듈 사양 확인 필요 |

### 위험도별 사용 예시

| 위험도       | 동작       |
| --------- | -------- |

```text
시연 전 실제 동작 전류를 측정해야 한다.
가능하면 모터 전원은 별도 5V 라인에서 공급하고 GND는 ESP32와 공통으로 연결한다.
```

## 6-2. 원통형 부저

| 항목       | 내용          |
| -------- | ----------- |
| 확인 상태    | 부분 확인       |
| 사진 표기    | 부품 표기 확인 불가 |
| 역할       | 청각 경고       |
| 사용 가능 여부 | 조건부 사용 가능   |

### 확인 필요 사항

```text
Active buzzer인지 Passive buzzer인지 확인 필요
정격 전압 확인 필요
소비전류 확인 필요
```

### Active / Passive 구분

| 종류             | 특징                | 제어 방식           |
| -------------- | ----------------- | --------------- |
| Active Buzzer  | 전원만 인가하면 소리가 남    | GPIO HIGH / LOW |
| Passive Buzzer | PWM 신호가 있어야 소리가 남 | PWM 또는 tone 제어  |

### 위험도별 사용 예시

| 위험도       | 동작       |
| --------- | -------- |
| SAFE      | OFF      |
| CAUTION   | 짧은 부저    |
| DANGER    | 반복 부저    |
| EMERGENCY | 빠른 반복 부저 |

### 주의사항

```text
부저 종류를 확인하지 않고 코드를 작성하면 소리가 나지 않을 수 있다.
전류가 큰 부저라면 ESP32 GPIO에 직접 연결하지 않는다.
필요 시 트랜지스터 또는 MOSFET 구동이 필요하다.
```

```text

```

### 저항 사용

| 저항   | 용도                     |
| ---- | ---------------------- |
| 220Ω | LED 직렬저항               |

```text
10kΩ은 LED 직렬저항으로는 너무 커서 매우 어둡거나 잘 보이지 않을 수 있다.
최종 RGB LED 모듈이 도착하기 전까지 단색 테스트용으로 사용한다.
```

### 예상 역할

```text

```

### 반드시 확인할 것

```text
3.7V LiPo 입력 시 5V 출력이 가능한가?
7.4V 입력 시 5V 출력이 안정적인가?
9V 입력 시 5V 출력이 안정적인가?
출력 전류가 ESP32 + 센서 + 진동모터 + 부저를 감당하는가?
```

### 주의사항

```text
사진만으로는 승압 모듈인지 강압 모듈인지 확정하기 어렵다.
LiPo 충전 기능이나 보호 기능이 있다고 보면 안 된다.
멀티미터로 입력 전압과 출력 전압을 반드시 확인해야 한다.
```

## 11. 현재 시연 전원 방향

현재 보유 부품 기준으로는 배터리 직접 구동보다 보조배터리 USB 5V 전원을 사용하는 것이 가장 현실적이다.

### 권장 시연 전원

```text
시중 보조배터리 USB 5V
→ ESP32 DevKit USB 포트
→ ESP32 및 센서 구동
```

또는

```text
시중 보조배터리 USB 5V
→ ESP32 확장 보드 USB 입력
→ ESP32 및 센서 구동
```

### 보고서 작성 방향

```text
실제 시연:
보조배터리 USB 5V 사용

최종 제품 설계:
3.7V LiPo 기반 보호회로 + 충전회로 + 5V 승압 모듈 사용 권장

현재 보유 배터리:
안전한 착용형 전원 구성에는 부족하므로 실험용으로만 분류
```

## 13. 최종 판단

현재 실제 보유 부품만으로 Smart Shield의 센서 수집, BLE 통신, 기본 출력 테스트는 가능하다.

다만 안전하고 안정적인 착용형 배터리 시스템은 현재 부품만으로 구성하기 어렵다. 따라서 시연에서는 보조배터리 USB 5V 전원을 사용하고, 최종 보고서에는 배터리 요구 규격과 권장 전원 설계안을 별도로 제시하는 것이 현실적이다.

현재 가장 중요한 미확정 항목은 다음과 같다.

```text
1. 부저가 Active인지 Passive인지 확인
2. HW-688 전원 모듈의 입력/출력 전압 실측
3. MAX30102 손목 착용 상태 측정 안정성 검증
4. RGB LED 모듈 도착 후 핀 구성 확인
5. MAX30205 / Fever Click 도착 후 I2C 주소와 배선 확인
6. 보조배터리 USB 5V 전원으로 전체 시연 가능 여부 확인
```

본 문서는 현재 보유 부품 기준의 하드웨어 현황 문서이며, 부품 추가 또는 변경 시 함께 갱신한다.
